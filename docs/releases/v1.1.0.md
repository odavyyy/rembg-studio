# Rembg Studio 1.1.0

Adds in-app updates, an About page and clearer privacy and licensing documents. **The interface is in Brazilian
Portuguese.** You need rembg installed; no model is included. See the README.

## Downloads

| File | What it is |
|---|---|
| `RembgStudio-Setup-1.1.0.exe` | Installer, per user. **Not tested.** |
| `RembgStudio-1.1.0-portatil.exe` | Single portable file. |
| `RembgStudio-1.1.0-win-x64.zip` | Extract and run `Rembg Studio.exe`. |
| `RembgStudio-1.1.0-Source.zip` | Source code of the tagged commit. |
| `SHA256SUMS.txt` | Checksums for the files above. |

The builds are **not code-signed**; Windows SmartScreen may warn you.

## Changes

- Manual update check, download with progress and cancel, SHA-256 verification, confirmation before installing.
- About page with documents and support links.
- One-time notice for `bria-rmbg`: **non-commercial use only**; commercial use needs an agreement with BRIA.
- ONNX Runtime telemetry is disabled for the app's rembg process.
- `elevate.exe` is no longer included.

Coming from 1.0.0: download this version by hand; 1.0.0 has no updater.

## Testing

**The packages attached by the release workflow are built on GitHub and have not been run or tested.** The results
below are from local builds of the same application code.

On one machine (Windows 11 Pro, RTX 5060 Ti): 33 app checks and 39 updater checks on packaged builds. The portable
version-to-version update was real, with a locally served test release and a stubbed confirmation; server failures
were simulated. Not tested: the installer, updating from a real published release, signed builds.
