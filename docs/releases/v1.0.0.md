# Rembg Studio 1.0.0

First public version of Rembg Studio, a Windows desktop app for background removal using
[rembg](https://github.com/danielgatis/rembg), with GPU acceleration and batch processing.
**The interface is in Brazilian Portuguese.**

## Downloads

| File | What it is |
|---|---|
| `RembgStudio-Setup-1.0.0.exe` | Installer, per user. **Not tested yet.** |
| `RembgStudio-1.0.0-portatil.exe` | Single portable file. Tested only for start-up and shutdown. |
| `RembgStudio-1.0.0-win-x64.zip` | Extract and run `Rembg Studio.exe`. This is the package the automated tests ran against. |
| `RembgStudio-1.0.0-Source.zip` | Source code of the tagged commit. |
| `SHA256SUMS.txt` | Checksums for the files above. |

**You also need rembg installed.** It is not included, and neither is any model. See the README for the install
commands. The builds are not code-signed, so Windows SmartScreen may warn you.

## What's in it

- Drag and drop, folder import, before/after slider, zoom and preview backgrounds.
- Batch queue, one image at a time, with cancel and reprocess.
- 16 local rembg models listed from your installation (with the default extras).
- Alpha matting and other mask options, with a memory guard for large images.
- Transparent PNG export that never overwrites your original images.
- Local history, saved settings and a real GPU test.

## Model licenses

`bria-rmbg` (RMBG 2.0) is for **non-commercial use only**; commercial use requires an agreement with BRIA.
Several other model weights have no license stated upstream. See the table in the README.

## Testing

32 automated end-to-end checks passed on the app extracted from the ZIP, using the real rembg installation and GPU on one
machine (Windows 11 Pro, RTX 5060 Ti 16 GB, rembg 2.0.88, Python 3.12, ONNX Runtime GPU 1.32.0). Native dialogs
were stubbed and drag and drop was injected through Chrome DevTools Protocol.

Not tested: the installer, ViTMatte, in-app model download, 13 of the 16 models, some batch buttons, keyboard
shortcuts, the "follow Windows" theme, CPU-only installs, other GPUs, other Windows versions.

## Known limitations

- Unsaved results are lost when the app is closed (the temporary cache is deleted at the next start).
- Images over 250 megapixels are rejected.
- Alpha matting is limited to 25 MP or less, depending on free RAM.
- EXIF metadata is not kept in exported PNGs.
